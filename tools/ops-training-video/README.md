# فيديو شرح الوحدة 1 (الجزء الثاني)

يبني فيديو MP4 بدقة 1920×1080 يشرح الجزء الثاني من الوحدة `m1` في منصة التدريب، من قسم «ماذا يعرف؟ ماذا يراجع؟ ماذا يكتشف؟ ماذا يرفع؟» حتى نهاية الحالة العملية.

- `script.json`: نص الشرح بالعامية المصرية، مقسّم إلى 26 مقطعًا. كل مقطع يحدد القسم الذي تتجه إليه الكاميرا (`cam`) والجزء المُبرز (`hl`).
- `build.py`: يولّد الصوت بـ edge-tts (`ar-EG-ShakirNeural`) ويأخذ توقيت كل كلمة، ثم يقود الصفحة الحقيقية بـ Playwright (تكبير وتحريك وإطار إبراز وترجمة عربية)، ثم يجمع الصورة والصوت بـ ffmpeg.

## التشغيل

```bash
pip install -r requirements.txt
playwright install chromium        # أو: --chromium /path/to/chrome
python build.py                    # الناتج: out/m1-part2.mp4
```

- `--voice-dir DIR`: استخدام تسجيلات صوتية بشرية بدل الصوت المولَّد. يكون في المجلد ملف لكل مقطع باسم رقمه (`01.m4a`، `02.mp3`…). يُقصّ الصمت من البداية والنهاية ويُوحَّد مستوى الصوت تلقائيًا، ويتبع طول كل مقطع طول التسجيل، وتعرض الترجمة النقاط الأساسية (`keys` في `script.json`) بدل النص الحرفي.
- `--no-tts`: معاينة صامتة بتوقيت تقديري، مفيدة لمراجعة الحركة قبل توليد الصوت.
- `--page PATH|URL`: استخدام نسخة محلية من الصفحة (الافتراضي تنزيل `index.html` من المستودع المصدر).
- تعديل النص: عدّل `script.json` وأعد التشغيل. يُعاد توليد صوت المقاطع التي تغيّرت فقط.
- سرعة الصوت: غيّر `"rate"` في `script.json` (مثل `"-5%"`) لضبط المدة بين 7 و8 دقائق.

يُخفي البناء طبقة العلامة المائية وشاشة الدخول ورسالة الترحيب في الصفحة، فلا يظهر أي اسم شخصي في الفيديو.
